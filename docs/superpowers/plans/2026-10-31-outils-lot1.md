# Lot 1 d'outils et expert Claude — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter à NozBar la météo, la recherche/ouverture de fichiers, les questions à l'utilisateur et le passage de main de Flash-Lite à Claude Sonnet.

**Architecture:** Catalogue d'outils neutre (JSON Schema) converti pour Gemini et Claude ; deux pilotes (`providers/gemini.ts`, `providers/claude.ts`) ; une `Conversation` qui choisit le pilote et bascule sur Sonnet via `ask_expert`. Actions Windows en Rust (fichiers, localisation).

**Tech Stack:** Tauri 2, Rust (`windows` 0.61, `strsim`, `deunicode`), React 19, TypeScript, `@google/genai` 2.32, `@anthropic-ai/sdk` 1.3, Vitest, Open-Meteo.

**Spec:** `docs/superpowers/specs/2026-10-31-outils-lot1-design.md`

## Global Constraints

- Textes visibles et messages d'outils en français.
- Modèle expert : `claude-sonnet-5-5` ; `effort: "medium"` ; `fallbacks: "default"` + beta `server-side-fallback-2026-07-01`.
- Modèles Gemini : `["gemini-flash-lite-latest", "gemini-flash-latest"]` (inchangé).
- Clés dans le Gestionnaire d'identification, service `NozBar`, comptes `gemini_api_key` / `anthropic_api_key`.
- Programmes (`exe msi msix appx bat cmd ps1 vbs js jse wsf scr com lnk reg jar hta cpl appref-ms`) : confirmation obligatoire.
- Dossiers fouillés : Téléchargements, Bureau, Documents ; profondeur ≤ 3 ; 20 000 entrées max ; 5 résultats max.
- Commentaires et nommage dans le style du code existant (commentaires en français, concis).

## Review Focus

1. Nom de fichier dicté avec extension ou fautes (« horzon launcher.exe ») → doit trouver `HorizonLauncher.exe`. Test : Tâche 2.
2. Échap pendant une question ou une confirmation → annule la question sans fermer la bulle. Test : Tâche 5 (`pending.ts`).
3. Claude demande plusieurs outils dans un même message → tous les `tool_result` dans un seul message utilisateur. Test : Tâche 6.
4. `days_ahead` hors limites (10, -1) → ramené entre 0 et 6. Test : Tâche 4.
5. Gemini appelle `ask_expert` en même temps qu'un autre outil → le passage de main l'emporte, l'autre appel n'est pas exécuté. Test : Tâche 7.
